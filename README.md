# DarkDrop - Anonymous File Drop Tool

DarkDrop is an anonymous file drop site that uses Tor for privacy and security. The tool allows users to upload files via a hidden .onion address.

## Features

- Creates a Tor-based .onion address for file uploads.
- Allows uploading files through a simple interface.
- Admin panel to manage uploaded files.

## Requirements

- Python 3.x
- Tor browser or Tor service installed on the system.

## Setup Instructions

1. Install Python 3.x from [here](https://www.python.org/downloads/).
2. Download and install the [Tor Browser](https://www.torproject.org/download/).
3. Clone or download the repository.
4. Ensure Tor is running on your machine.
5. Run `darkdrop.py` with Python.

```bash
python darkdrop.py
